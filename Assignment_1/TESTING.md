| Test Case | Input | Observed Result |
|---|---|---|
| Addition | 5 + 4 | 9 |
| Subtraction | 6 - 3 | 3 |
| Multiplication | 8 * 2 | 16 |
| Division | 9 / 3 | 3 |
| Division by Zero | 7 / 0 | "Error: Cannot divide by zero" |

## Error Tests
1. A test was performed where "number" was entered instead of an actual number when prompted for the first number. Results displayed "Invalid input. Please enter a number."
2. A test was performed where "maybe" was entered instead of "yes" or "no" when asked if the user would like to perform another calculation. Results displayed "Invalid Input".
3. A test was performed where "5" was entered instead of a number from 1-4 when asked which operation the user would like to perform. Results displayed the question again, prompting them to pick a number 1-4.
