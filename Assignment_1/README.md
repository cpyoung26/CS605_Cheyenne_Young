# Simple Calculator

## Description

Simple Calculator is a console-based Python program that performs basic arithmetic operations between two numbers. 

## How to Use

To use Simple Calculator, follow the steps: 

1. Run the `calculator.py` program in Python.
2. The program will prompt you to select an operation (1. Add, 2. Subtract, 3. Multiply, 4. Divide). Type in the number associated with the operation you want to perform in the terminal. 
3. The program will prompt you to enter the first number in the operation; enter the number in the terminal.
4. The program will then prompt you to enter the second number in the operation; enter the number in the terminal.
5. The program will display the answer.
6. The program will ask if you would like to perform another calculation. Enter `yes` or `no`. If yes, the program will start over. If no, the program will display an end message.

## Operations 
The following operations are available: 

1. Addition
2. Subtraction
3. Multiplication
4. Division
